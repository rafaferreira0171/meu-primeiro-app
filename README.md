# LookLiP Finance

Independent reconstruction of the user's former Base44 personal finance app.

## Modules
- Fluxo
- Empregada
- Pix
- Entradas x Budget
- LookLiP Dash

## Current stage
The repository contains the independent React/Vite MVP. It currently uses browser localStorage and a development-only login shell. The next stage is a real hosted database/authentication layer, Base44 data migration, production validation, and mobile packaging.

The original Base44 project remains preserved separately.
